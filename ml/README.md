# Machine Learning Module

ML models for medical risk prediction.

## Status

Not yet initialized. Models will be trained in a later phase.

## Planned Models

- Diabetes risk prediction (Scikit-learn / XGBoost)
- Heart disease risk prediction (Scikit-learn / XGBoost)
- Kidney disease risk prediction (Scikit-learn / XGBoost)

## Approach

- Train on publicly available medical datasets
- Use deterministic reference-range analysis for Low/Normal/High/Critical classification
- ML models provide supplementary risk scores, not diagnoses
